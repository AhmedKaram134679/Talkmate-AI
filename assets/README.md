# Assets Directory

هذا المجلد مخصص لجميع الموارد (Assets) الخاصة بتطبيق TalkMate AI.

## هيكل المجلدات:

- **icons/**: أيقونات التطبيق والواجهات
- **logo/**: شعارات التطبيق بأحجام مختلفة
- **illustrations/**: الرسوم التوضيحية والصور
- **sounds/**: الأصوات والتنبيهات الصوتية
- **backgrounds/**: خلفيات الشاشات
- **fonts/**: الخطوط المخصصة
- **ui-components/**: مكونات واجهة المستخدم

## ملاحظة مهمة:
سيتم تسليم جميع الموارد لاحقاً في مجلد منظم وجاهز للاستخدام.
جميع الموارد مجانية وخالية من مشاكل حقوق النشر.
